# Phase 2 关键神经元实验报告

## 目的

验证关键神经元这条线索能否接进差分基座。要确认三件事：关键神经元能被识别出来且占比合理，覆盖率从一个不饱和的初值随变异增长，覆盖目标的梯度能真正推动覆盖增长。这三件事直接对应实现方案第七章的硬检查，也针对旧实现暴露的两个问题——覆盖率第一轮就饱和、覆盖梯度恒为零。这一轮还顺带跑了融合权重 α 的两个极值，看清频率项和归因项各自的作用。

## 设置

关键神经元由两个维度融合得到。频率维度统计神经元在训练样本上被激活的比例。归因维度度量神经元对目标类别输出的敏感度，

$$S(n, c) = E_{x \in D_c}\left[\left| \frac{\partial F(x)_c}{\partial \text{out}(n, x)} \cdot \text{out}(n, x) \right|\right]$$

综合关键度按权重 α 融合，

$$cl(n, T) = \alpha \cdot \text{Freq}(\text{out}(n, T) > t) + (1 - \alpha) \cdot \text{Norm}(S(n, c))$$

α 是唯一的关键度配置开关。α=1 取纯频率，α=0 取纯归因，中间为融合。

关键集合有两套，用两个分位阈值分别切。全局集合 $\mathcal{D}_{en}$ 用宽阈值 $\tau_{global}$，保留 $cl$ 高于该分位的神经元，占比约 $1-\tau_{global}$，撑起 CNCov 的广度。类关键集合 $\mathcal{D}_{en}^c$ 用更严的 $\tau_{class}$，按各类自己的 $cl_c$ 取一个小而类专属的集合，撑起 CCCov 的类区分。

覆盖率有两个。CNCov 是已覆盖关键神经元占 $\mathcal{D}_{en}$ 的比例，一个关键神经元只要被某个样本激活就算覆盖。CCCov 把同一本全局覆盖账投到各类的 $\mathcal{D}_{en}^c$ 上，看类别之间覆盖是否均衡。覆盖账只有一本，CCCov 的类间差异来自各类集合本身不同，不靠按类别分别记账。

覆盖目标每轮从未覆盖的关键神经元里选一组 $\mathcal{U}$，优先选接近激活阈值且与当前种子类别相关的神经元，

$$obj_{cov}(\mathbf{x}) = \sum_{n \in \mathcal{U}} \text{out}(n, \mathbf{x})$$

$\mathcal{U}$ 取一组神经元求和，不是只取第一个未覆盖神经元，后者在覆盖饱和时梯度恒为零。

变异同时受差分目标和覆盖目标驱动。两个目标各自对输入求梯度，先按各自的 L2 范数归一化再加权合并，最后取符号做投影梯度上升。先归一化是因为两个目标的梯度量纲不一致，直接相加会让覆盖项被差分项淹没。合并权重由 $\lambda_2$ 控制，$\lambda_2 = 0$ 时退化为带覆盖跟踪的纯差分，用作对照。profiling 只跑一次并按参数缓存。

## 与实现方案的工程偏离

实现层面有五处偏离实现方案 4.2 字面写法的工程决定，都是在 mini-ImageNet 上实测后做的调整。前四处为守住硬检查，第五处是一处暂未修复的已知问题。每条都能用 `scripts/demo_phase2_decisions.py` 在目标模型上复现，括号里的数字取自该脚本一次运行的输出。

第一处是激活的归一化。实现方案写的是 $\text{out}(n) > t$，直接拿固定阈值卡原始激活。但各层激活量纲差异大，固定 $t$ 下层均激活比例从 0 一直到 0.65、标准差 0.138，有的层在 $t = 0.5$ 下完全没有神经元激活，这些层等于被这条阈值悄悄整层排除出覆盖。改成按每个神经元在 profiling 样本上的峰值归一化后，$t$ 表示超过自身峰值的若干比例，每层都进得来，层均比例落在 0.002 到 0.303、标准差降到 0.072。频率统计、覆盖判定、覆盖目标复用同一套尺度。

第二处是归因的 Norm。实现方案只说归一化到与频率可比。归因 $S$ 长尾极重，min-max 归一化下中位数和 90 分位都几乎是 0，融合时 $(1-\alpha)$ 这一项形同虚设，$cl$ 退化成只由频率决定。改成百分位归一化后 $S$ 均匀铺开到 $[0,1]$，与频率口径一致。

第三处是关键神经元的选取方式。实现方案写的是绝对阈值 $cl > \tau$。修好 Norm 之后 $cl$ 的中位数约 0.28，但绝对阈值仍然不可移植：同一个 $\tau = 0.5$ 下绝对阈值只选出 2.6% 的神经元，想选到 50% 得把 $\tau$ 压到模型相关的某个值，只能先测才知道。改成分位阈值后，保留 $cl$ 高于 $\tau$ 分位的神经元，占比直接约等于 $1 - \tau$：$\tau = 0.5$ 选 50%，$\tau = 0.2$ 选 80%，$\tau = 0.9$ 选 10%，整条线落在预期区间内，且 $\tau$ 越大越严的方向和绝对阈值一致。

第四处是类关键集合的阈值和 CCCov 口径。实现方案把 $T$ 换成 $T_c$ 得 $\mathcal{D}_{en}^c$，隐含它和全局集合用同一个 $\tau$。实测在全局占比取 50% 这么大时，各类别的 $\mathcal{D}_{en}^c$ 高度重合（每类约 13780 个，两两 Jaccard 0.949）——高置信度共识种子下，类别专属的差异落在长尾、进不了前 50%。这时把全局覆盖账投到各类，CCCov 各类几乎一样（标准差 0.0030），分不出类别。改成给类关键集合单设一个更严的 $\tau_{class} = 0.9$ 后，每类集合缩到约 2756 个、两两 Jaccard 降到 0.841，CCCov 跨类标准差升到 0.0129，能反映类别间不均衡、指导调度向覆盖不足的类别倾斜。

第五处是归因项当前近乎惰性，这是一处已知问题，暂未修。$S(n,c)$ 里的 $F(x)_c$ 实现取的是 softmax 概率。在高置信的共识类训练数据上，概率已接近 1、softmax 进入平台区，$\partial F_c / \partial \text{out} \approx 0$，于是 $S \approx 0$ 几乎处处成立，百分位归一化后退化成神经元下标顺序。后果是 α=0 纯归因时各类 $\mathcal{D}_{en}^c$ 完全相同、CCCov 标准差精确为 0，$cl$ 由一个位置性的伪信号决定；α=0.5 融合时类区分其实全部来自逐类频率，$(1-\alpha)$ 这项没起作用。候选修法是把 $F(x)_c$ 从 softmax 概率换成 logit，logit 不饱和、能恢复归因的真实量级。但这处修法的收益要到 Phase 5 有了 #Classes、缺陷簇数、OI 这些多样性指标后才能判定，所以这一阶段先记录，留到 Phase 5 评估。

这几处偏离记录在实现方案第十章，4.2 的原文保持不动。

## 复现

实验在仓库根目录运行，环境由 uv 管理。先确认 `datasets/imagenet` 符号链接有效再同步环境，然后跑 diff+cov 主实验、它的 $\lambda_2 = 0$ 对照，以及 α 的两个极值。

```bash
uv sync
uv run python scripts/run_fuzz.py --config configs/diff_cov.toml       # 主实验 α=0.5
uv run python scripts/run_fuzz.py --config configs/diff_cov_lam0.toml   # λ2=0 对照
uv run python scripts/run_fuzz.py --config configs/diff_cov_a0.toml     # α=0 纯归因
uv run python scripts/run_fuzz.py --config configs/diff_cov_a1.toml     # α=1 纯频率
```

`profile_neurons.py` 单独做 profiling 并打印关键度分位数和各候选 $\tau$ 下的占比，用来校准阈值。`demo_phase2_decisions.py` 把上面五处偏离的依据在真实模型上打印出来。

```bash
uv run python scripts/profile_neurons.py --config configs/diff_cov.toml
uv run python scripts/demo_phase2_decisions.py --config configs/diff_cov.toml
```

所有参数都在 TOML 里。`configs/diff_cov.toml` 是主配置，其余三份只改一两个字段、各自另开输出目录。关键参数如下。设备 CUDA，全局随机种子 42。目标模型 resnet50，参考模型 vgg16_bn 与 mobilenet_v2。mini 模式下种子取自每类留出的 20%（`val_fraction = 0.2`），候选种子数 200；频率统计取自 train 中除去种子池的那 80%，全量流式，不另抽子集。归一化激活阈值 $t = 0.5$，全局分位阈值 $\tau_{global} = 0.5$，类关键分位阈值 $\tau_{class} = 0.9$，融合权重 $\alpha = 0.5$，每类归因样本上限 32。变异 L∞ 上界 0.03，步长 0.01，PGD 步数 10，目标神经元集合大小 16，覆盖目标权重 $\lambda_2 = 0.5$。profiling 结果缓存在 `output/profiles`，参数不变就直接复用。

## 结果

共识过滤接受 200 个种子中的 162 个，接受率 0.81，覆盖 59 个共识类别。这一步完全确定，每次都一样。

关键神经元识别正常。目标模型经 profiling 共 27560 个神经元，$\tau_{global} = 0.5$ 下关键神经元 13780 个，占比 0.50。占比由分位阈值直接控制，$\tau = 0.2$ 时占比 0.80，$\tau = 0.9$ 时 0.10，整条线落在实现方案参考的 30%–82% 区间内，没有接近 100%。

覆盖率从一个不饱和的初值随变异增长。diff+cov 主实验里初始种子覆盖率 $CNCov_0$ 为 0.348，明显小于 1，留出了增长空间。它随迭代单调上升，最终到 0.588，增长 0.240，结束时仍有 5679 个关键神经元未覆盖，没有第一轮就饱和。

覆盖梯度非零。整个过程覆盖目标对输入的梯度均范数约 14.6，结合上面那 5679 个未覆盖神经元，说明在存在未覆盖神经元时覆盖梯度确实大于零，不是旧实现那种恒为零。

覆盖目标的作用通过 $\lambda_2 = 0$ 对照看得很清楚。两组用同一份 profiling、同样的种子、同样的差分信号，唯一区别是开不开覆盖目标。

| 指标 | $\lambda_2 = 0$ | $\lambda_2 = 0.5$ |
| --- | --- | --- |
| CNCov 终值 | 0.456 | 0.588 |
| CNCov 增长 | 0.108 | 0.240 |
| 候选缺陷数 | 158 | 153 |
| RFT | 0.975 | 0.944 |
| 覆盖梯度均范数 | 19.3 | 14.6 |

开覆盖目标后 CNCov 增长从 0.108 升到 0.240，是关掉覆盖目标的两倍多，并且 diff+cov 的覆盖曲线在每一轮都不低于对照。代价是候选缺陷略减、RFT 从 0.975 降到 0.944，因为一部分梯度方向让给了覆盖探索。这符合预期，也印证了 Phase 1 的判断：覆盖模块的收益体现在覆盖增长上，不体现在缺陷数量上。顺带一提，$\lambda_2 = 0$ 这组（158 缺陷、RFT 0.975）和纯差分 base（157 缺陷、RFT 0.969）几乎一致，说明它确实就是 base 加了一套覆盖跟踪，覆盖跟踪本身不改变缺陷结果。

α 的两个极值揭示了频率项和归因项各自的脾性。三组都开覆盖目标（$\lambda_2 = 0.5$），只改 α。

| 指标 | α=0 纯归因 | α=0.5 融合 | α=1 纯频率 |
| --- | --- | --- | --- |
| $CNCov_0$ | 0.273 | 0.348 | 0.660 |
| CNCov 终值 | 0.509 | 0.588 | 0.859 |
| CNCov 增长 | 0.236 | 0.240 | 0.198 |
| 未覆盖终值 | 6768 | 5679 | 1945 |
| 覆盖梯度均范数 | 14.8 | 14.6 | 9.87 |
| 候选缺陷数 | 160 | 153 | 146 |
| RFT | 0.988 | 0.944 | 0.901 |

纯频率（α=1）最值得注意。它的关键集合全是高频神经元，本来就容易被激活，所以 $CNCov_0$ 一上来就 0.660，到结束爬到 0.859、未覆盖只剩 1945，已经接近饱和。覆盖梯度均范数也最低（9.87），因为大多数关键神经元早就过线、没什么可推的。这正是频率项的固有偏向：它挑出来的就是好覆盖的神经元，覆盖率因此跑得快、也更快触顶。纯归因（α=0）反过来，$CNCov_0$ 最低（0.273），起点留的空间最大，但它的逐类集合是退化的（见偏离第五处），这个低起点带有偶然性，不能当成归因真在挑难覆盖的神经元。融合（α=0.5）落在两者之间。

CCCov 反映出类别间不均衡。按严的 $\tau_{class}$ 取类关键集合后，初始各类覆盖率分布在 0.41 到 0.47 之间、跨类标准差 0.0129，各类不再一致，这个信号可供后续调度把种子向覆盖不足的类别倾斜。但要诚实指出，CCCov 随迭代涨得很快，到结束时各类都到了 0.93 上下，比 CNCov 的 0.588 高出一大截，也接近饱和。原因还是上面那条：类关键集合的 $cl$ 一半是频率，挑出来的偏向高频易覆盖神经元，所以 CCCov 起点就比 CNCov 高、涨得也快。这意味着 CCCov 作为调度信号在迭代后期会逐渐失去区分力，和归因项惰性是同一个根源。

缺陷记录现在额外存了样本在关键神经元集合上的归一化激活向量，作为内部路径指纹，供 Phase 5 的缺陷聚类用。

变异阶段在 CUDA 上有微小非确定性，候选缺陷数会上下浮动几个，覆盖率小数末位也会轻微变化，结论不受影响。

## 观察与建议

关键占比由分位阈值控制后变得可调，这让后续消融很自然：固定占比、只切换 α 在 0、0.5、1 之间，比较的是同样大小但成员不同的关键集合，干净。

这一轮最重要的发现是归因项现在没真正起作用。softmax 在高置信训练数据上饱和，把归因敏感度压成了近乎处处为零，所以现在的融合实质上由频率主导，纯归因那一极是退化的。这件事的连锁后果，是 CCCov 也跟着偏向频率、涨得过快。把归因目标从 softmax 概率换成 logit 是已经看清的修法，但它的真实收益要看类别多样性和缺陷簇结构有没有变好，而这些指标属于 Phase 5。在那之前改了也没法验收，所以这一阶段先记录、不动代码，等 Phase 5 把多样性指标建起来后，直接比 softmax 默认和 logit 在 #Classes、缺陷簇数、CCCov 区分度上的差异，再决定。

覆盖目标和差分目标的权衡当前用 $\lambda_2$ 静态控制。Phase 4 的动态反馈会根据覆盖增长和缺陷触发情况在线调 $\lambda_2$，预计能在不怎么牺牲缺陷数的前提下保住覆盖增长。

## 结论

Phase 2 达标。关键神经元能识别且占比落在合理区间，CNCov 从不饱和的初值（0.348）单调增长到 0.588，覆盖梯度在存在未覆盖神经元时大于零（均范数 14.6，未覆盖 5679），diff+cov 的覆盖曲线在每一轮都高于纯差分。三条硬检查全部通过。模块该交付的也都齐了：profiler 的频率与归因融合、coverage 的 CNCov 与 CCCov、objective 的 $\mathcal{U}$ 选取、diff+cov 接入、缺陷的关键神经元激活向量记录。实现上有五处为适配数据做的工程调整，前四处已守住硬检查，第五处归因项惰性是一处已知问题，候选修法（logit）和验收依赖（Phase 5 多样性指标）都已写明，留待 Phase 5 处理。
