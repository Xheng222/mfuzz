# 调度文件模板

复制成 调度-<标签>.md 开一个调度者。下面每块说明怎么填，规则见 调度规范.md。

头部字段：

```
---
orchestrator: <标签>
domain: <管哪些流>
updated: <最后改动时间>
---
```
