# 调度文件模板

复制本文件并命名为 `调度-<标签>.md`，即可创建一个调度者文件。各字段的填写规则见 `调度规范.md`。

头部字段：

```yaml
---
orchestrator: <标签>
domain: <负责的工作流>
updated: <最后改动时间>
---
```
