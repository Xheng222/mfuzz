## 目标

让归因分析覆盖检测的四类失效，也就是虚检、漏检、误分类、定位偏移。每一类都要给出责任层级的特征、因果验证的结论、能用的修复办法和它的代价。虚检和漏检已经做成，这条流补齐误分类和定位偏移。

## 已知上下文

- [决定] 方法不限，以做出效果为准，training-free 不再是硬约束。
- [方法] A、B 两集不相交：A 选责任通道，B 评测。判据用项目的 differential judge，不用 mAP。
- [结论] 虚检、漏检抑制责任通道可修，效果明显超过随机对照，因果性成立。已复核。
- [结论] 定位偏移因果性成立，但抑制和单步改权重都修不动。已复核。
- [假设] 误分类挂回归头时责任通道和随机分不开，疑似归因层选错，待重归因到分类子网验证。
- [坑] COCOeval 不在代码里，别拿 mAP 当判据。
- [坑] profile 缓存的 key 不含图片数量，跨 run 复用，注意别误用上一次的旧缓存。

## 作业队列与下一步

GPU 一次只能跑一个，按顺序排。依赖关系写在每条后面。

1. 误分类重新归因到分类子网，看责任通道能不能明显超过随机对照。做到能分清就算成。
2. 用上一步的定位来修误分类，先试抑制，不行就用定向微调。要等第 1 条。
3. 定位偏移用定向微调来修，只解冻责任层，做几步带 IoU 的微调。
4. 多次划分 A 和 B，跑出方差，给一个能报告的区间。要等第 1 到 3 条出结果。
5. 把虚检和漏检的抑制修复用到其它模型上，看是不是普遍成立。
