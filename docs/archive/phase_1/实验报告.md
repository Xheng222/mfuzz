# Phase 1 差分基座实验报告

## 目的

验证差分基座能否跑通。要确认共识过滤、差分目标、四类分流三件事串起来能产出候选缺陷，并且五项差分指标取值合理。

## 设置

三个 ImageNet 模型 resnet50、vgg16_bn、mobilenet_v2 互为交叉引用。种子取自本地 mini-ImageNet 的验证集，先经共识过滤，只保留三个模型预测一致的样本，把一致预测记为共识标签。

变异用投影梯度上升，运行在 [0,1] 像素空间。每步沿差分目标 obj_1 增大的方向走，目标是让目标模型降低对共识标签的置信度，同时让参考模型维持。L∞ 扰动上界取 0.03，步长 0.01，走 10 步。默认目标模型是 resnet50。为验证目标轮换，另跑了一组以 mobilenet_v2 为目标。

## 复现

实验在仓库根目录运行，环境由 uv 管理。先确认 `datasets/imagenet` 符号链接有效，再同步环境，然后用默认配置跑主实验。

```bash
uv sync
uv run python scripts/run_fuzz.py --config configs/base.toml
```

所有参数都在 TOML 里，命令行只选配置文件。`configs/base.toml` 是默认配置，主实验直接用它：种子数 200，目标模型 resnet50，模式 diff，结果写到 `output/diff`。要换实验就复制一份配置改对应字段，省略的字段会回落到代码里的默认值。比如轮换目标到 mobilenet_v2，复制一份把 `[models]` 的 target_idx 改成 2、`[run]` 的 out 改成新目录，再用 `--config` 指定运行。

环境与关键参数如下。设备 CUDA，全局随机种子 42，种子采样固定这个种子，结果可复现。三个模型都用 torchvision 预训练权重，resnet50 用 IMAGENET1K_V2，vgg16_bn 用 IMAGENET1K_V1，mobilenet_v2 用 IMAGENET1K_V2。变异参数：L∞ 上界 0.03，步长 0.01，PGD 步数 10，obj_1 的 lambda1 取 1.0。共识过滤的低置信度阈值 0.1。共识预测用批大小 32，变异用批大小 8。结果写在 `[run]` 的 out 目录下的 `result.json`，含五项指标与逐步目标置信度曲线。

## 结果

resnet50 作目标，200 个种子的主结果如下。

| 指标 | 取值 |
| --- | --- |
| 种子接受率 | 0.77（154/200） |
| 候选缺陷数 | 152（154 个被变异种子中） |
| RFT（候选缺陷触发率） | 0.99 |
| 参考共识保持率 | 1.00 |
| 目标置信度平均下降 | 0.47 |
| 平均扰动（L∞） | 0.03 |

目标模型对共识标签的置信度随迭代单调下降，十步均值为 0.47、0.14、0.05、0.025、0.012、0.007、0.004、0.003、0.003、0.003。下降趋势清楚。

共识过滤完全确定，接受率每次都是 0.77。变异阶段在 CUDA 上有微小非确定性，候选缺陷数会在 154 个里上下浮动一个，RFT 稳定在 0.99 附近。

轮换到 mobilenet_v2 作目标，种子接受率 0.79，RFT 1.00，目标置信度平均下降 0.40。不同架构的触发情况存在差异，轮换路径可用。

## 观察与建议

RFT 接近饱和。eps 取 0.03 是一个较强的扰动预算，在白盒条件下目标模型几乎必然被推离共识，而参考模型几乎必然保持。这说明差分机制本身是对的，但也意味着 RFT 在这个预算下失去了区分度。

为确认这一点，固定 64 个种子、resnet50 作目标，只改 eps 扫了三档。eps 0.03 时 RFT 0.99，eps 0.01 时降到 0.74，eps 0.005 时降到 0.28。RFT 随扰动预算单调变化，eps 越小越离开饱和区。eps 降到 0.005 时参考共识保持率也从 1.00 略降到 0.98，说明预算太小时参考模型偶尔也会被带偏。这条曲线说明 RFT 的饱和来自预算大小，不是机制缺陷。

由此带来一个对后续阶段的提醒。关键神经元覆盖和语义约束这两个模块的贡献，应该体现在覆盖增长、缺陷多样性和语义有效率这些维度上，而不是 RFT。研究方案本来也是这样安排的，覆盖的评价指标是 CNCov 增长和缺陷簇数，不是缺陷数量。如果 Phase 6 的消融希望在缺陷发现率上也看到各模块的增量，可以把 eps 调小，让 RFT 离开饱和区，留出可比较的空间。这是一个标定问题，留到 Phase 4 和 Phase 6 再定。

## 结论

Phase 1 达标。五项差分指标都能算出且取值合理，RFT 大于零，参考共识保持率正常，目标置信度随迭代下降，目标轮换可用。
