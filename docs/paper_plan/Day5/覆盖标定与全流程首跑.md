# 覆盖标定修正与全流程首批运行记录

日期：2026-06-11 至 2026-06-12。本文记录覆盖标定数据源的修正过程，以及统一框架下检测与分类两类任务的首批全流程运行结果。

## 标定数据源的问题与修正

重构后的首次 E1 运行暴露了一个问题：三个检测器的初始覆盖 CNCov_0 都在 0.99 以上，循环没有增长空间。排查后确认，根因在 profiling 的数据来源。旧实现从 val2017 取 100 张图做标定，样本太少，关键单元的激活区间和频率估计都不可靠。这是分类阶段遗留下来的做法，当时本地数据集太小，只能使用小样本。

按 CriticalFuzz 的定义，关键度 cl(n,T) 统计的是训练集上激活该神经元的样本占比，论文在完整训练集（5 万到 6 万张）上计算。修正后的做法与此对齐：检测标定改用 COCO train2017 全量（118287 张）。分类任务本来就在全量训练集上做 profiling，这次修正让两类任务的统计方式一致。

全量数据不能一次性放入显存。118287×43123 的矩阵约 20GB。因此，实现改为两遍流式统计：第一遍逐图累计每个单元的 min/max，第二遍按 0.3/0.5/0.7 三档 t_freq 同时累计激活频率。统计结果写入缓存（`output/profiles/det_<模型>_<集名>_n<图数>.pt`）。critical_tau 与 t_cov 是事后参数，不写入缓存，因此更换参数不需要重新统计。

中途遇到一个工程问题：train2017 中有损坏文件（000000079035.jpg，2014 年的原始损坏，PIL 无法识别），三个标定任务在同一张图上全部失败。修复方式是读图失败时跳过并告警，频率分母改用实际处理数。

## 临时参数下的 E1 重跑

全量标定需要数小时，因此先用 train2017 前 1000 张做了一版临时标定。扫描 t_cov 后取 0.95，使三模型的 CNCov_0 落在 0.46 到 0.51。用这版参数重跑 E1（50 轮，三模型轮换），覆盖动态恢复正常：

| 模型 | CNCov_0 | CNCov_final | 新失效 | 语义有效率 |
|---|---|---|---|---|
| faster_rcnn | 0.458 | 0.677 | 941 | 0.96 |
| retinanet | 0.479 | 0.740 | 612 | 0.93 |
| fcos | 0.490 | 0.729 | 978 | 0.94 |

自然失效分析部分与 Day 5 独立脚本的数字完全一致，失效计数、真值核验裁决构成逐项相同，说明迁移进统一框架没有引入行为变化。层级结构定位结果保持稳定：faster_rcnn 偏 P2，retinanet 偏 P5/P6，fcos 偏 P3/P4。自然与生成失效的结构对比（E6 数据源）同样保持：fcos 的 loc 失效在自然与生成两侧都由 head.reg 主导，份额比为 3.6 对 4.2，生成侧放大了自然结构分布。

这版结果的标定只用了 1000 张图，因此定位为中间版。全量标定（118287 张）完成后，会按参数网格重新定参并重跑。正式的 E1 数字以全量标定版为准。

## 分类任务首次端到端运行

`cls/imagenet100` 配置在服务器上完整通过，这是分类适配器在统一框架下的第一次端到端验证。数据集使用 imagenet-100，通过软链接接入。train 13 万张用于 profiling，种子取自 val。模型使用 resnet50，循环 100 轮。

关键数字：CNCov 从 0.306 涨到 0.691，逐类覆盖 CCCov 均值从 0.55 涨到 0.99，新失效 264，语义有效率 0.82，共识保持率 1.0。动态权重正常响应：λ3 随语义漂移波动，λ2 在覆盖停滞时上调。循环曲线、缺陷聚类、分布图全部正常产出。统一框架的两个任务适配器至此都有完整运行证据。

## 全量标定与参数网格

三个模型的全量标定任务在服务器上并行执行。faster_rcnn、retinanet、fcos 分别压在 GPU 3/2/1，每个任务两遍扫描约五到六小时。标定完成后，`scripts/calibrate_det_tcov.py` 在缓存上离线扫描参数网格：t_freq 三档 × critical_tau 三档 × t_cov 七档，共 63 个组合，逐个报告关键单元数与种子集初始覆盖。结果写入 `output_det/tcov_scan/<模型>.json`。定参标准是：三个模型的 CNCov_0 接近，并且留有增长空间。

网格结论（2026-06-12 晚）：全量标定把 min/max 区间拉宽之后，三个设计默认参数原样成立，即 t_freq=0.5、critical_tau=0.5、t_cov=0.85。三模型 CNCov_0 = 0.411/0.428/0.441，带宽 0.03；关键单元数为 16134/21563/19664。t_cov 在 0.85 到 0.95 之间梯度极陡，0.90 档骤降到 0.15 左右。中间版需要 0.95，原因是 1000 张小样本把区间估窄了。

## E1 正式版与 E5 消融

定参后，base/diff/nofb 三组并行重跑。它们使用标定缓存，每组约 15 分钟。实际运行的 CNCov_0 = 0.410/0.425/0.429，与网格预测一致。三组对比如下，50 轮，按 faster_rcnn/retinanet/fcos 排列：

| 组 | 覆盖增量 | 新失效 | 语义有效率 | OOD 单元 |
|---|---|---|---|---|
| base 完整反馈 | +0.224 / +0.208 / +0.227 | 1022 / 797 / 714 | 0.93 / 0.92 / 0.92 | 1686 / 2585 / 3774 |
| diff 纯差分 | +0.007 / +0.055 / +0.062 | 1186 / 490 / 479 | 0.92 / 0.57 / 0.40 | 78 / 437 / 827 |
| nofb 静态权重 | +0.052 / +0.065 / +0.079 | 1556 / 1021 / 1125 | 1.0 / 1.0 / 1.0 | 524 / 590 / 1120 |

三条结论。覆盖项有效：base 的覆盖增量是另外两组的 3 到 4 倍，OOD 单元探索量高一个量级。语义项必要：diff 在 retinanet/fcos 上有效率降到 0.57/0.40，纯差分梯度破坏图像严重，有效失效反而最少。动态调整体现了取舍：nofb 原始失效最多、有效率 1.0，但覆盖几乎不增长；base 用约三成失效数换取 3 倍覆盖。失效数量仍需要结合聚类与结构多样性解读，留给大纲讨论。

注意：本表与上面 E1 表的"新失效"列都是触发记录数，只对种子的自然基线去重，同一缺陷跨轮重复触发会重复计数。2026-06-13 起，评测端增加按身份去重的独特缺陷指标，见 `核心贡献与实验矩阵.md` 的分层一节。复核结果见下文"五档基线对照"一节：按独特缺陷统计时，base 全面领先，nofb "失效最多"是重复触发造成的表象，效率结论在修正后反而更强。

## E10 随机基线

随机基线 RandomMutator 使用同 ε 预算的均匀噪声，没有任何引导。它与完整框架在同预算下对比，预算为 50 轮 × 每轮 4 图，按变异次数定义。真值核验由生成失效真值核验产出：扰动是 ε 球内像素噪声，几何不变，因此种子图的 GT 框可以直接套用，裁决标准与自然侧一致。指标按矩阵文档"评测与机制的分层"一节修正：主指标是独特缺陷（种子图+类型+位置聚类去重）及其真值确认，触发记录数降为次要观测。数字为 06-13 修正版运行（random_run3/base_run6），按 faster_rcnn/retinanet/fcos 排列：

| 组 | 触发记录 | 独特缺陷 | 真值确认(独特) | 确认率(独特) | 覆盖增量 | OOD 单元 |
|---|---|---|---|---|---|---|
| random 无引导 | 337 / 258 / 248 | 111 / 91 / 92 | 73 / 48 / 53 | 0.66 / 0.53 / 0.58 | +0.023 / +0.032 / +0.017 | 40 / 629 / 106 |
| base 完整框架 | 1118 / 749 / 688 | 340 / 155 / 260 | 303 / 122 / 221 | 0.89 / 0.79 / 0.85 | +0.206 / +0.223 / +0.256 | 1959 / 3044 / 5130 |

五个结果。独特缺陷数：完整框架是随机基线的 3.1/1.7/2.8 倍。去重确实缩小了触发记录层面的差距，retinanet 从 2.9 倍缩到 1.7 倍，base 的 miss 记录重复率高达 9 倍，但核心假设经受住了这一修正。真值确认的独特缺陷：完整框架是随机基线的 4.2/2.5/4.2 倍，确认率高出 23 到 27 个百分点，说明引导找到的独特缺陷中真缺陷比例也更高。重复触发率（触发记录/独特缺陷）：base 为 3.3/4.8/2.6，random 为 3.0/2.8/2.7，引导会对同一缺陷反复施压，这正是去重必要性的直接证据。失效多样性：random 在 faster_rcnn 上的独特缺陷几乎全是 spurious，数量为 101 个，loc 仅 1 个，miss 仅 2 个；base 四类全部达到两位数。覆盖探索：随机噪声覆盖增量不足完整框架的七分之一，OOD 单元少一到两个量级。运行方差：random 完全确定，三次运行逐项相同；base 的 PGD 在 GPU 上非确定，触发记录跨运行波动约 ±20%，独特缺陷数的跨运行方差待多次运行统计，正式报告按区间报告。

与分类器阶段"完整框架触发总数低于纯 PGD、但种类更高"的观察相比，base 对 random 是两项全胜。两者不矛盾，因为 random 不是纯 PGD。该现象在检测侧的对应检验见下节四档对照。

## 五档基线对照（独特缺陷，06-13）

diff/nofb/corruption 按修正指标重跑，运行名为 diff_run2/nofb_run2/corrupt_run2，基线表由此补全。按 faster_rcnn/retinanet/fcos 排列：

| 组 | 触发记录 | 独特缺陷 | 真值确认(独特) | 确认率(独特) | 语义有效率 |
|---|---|---|---|---|---|
| random 无引导 | 337 / 258 / 248 | 111 / 91 / 92 | 73 / 48 / 53 | 0.66 / 0.53 / 0.58 | 1.0 |
| corruption 腐蚀(强度 3) | 312 / 140 / 75 | 168 / 82 / 63 | 114 / 34 / 40 | 0.68 / 0.41 / 0.63 | 0.31~0.63 |
| diff 纯差分梯度 | 1197 / 518 / 485 | 40 / 69 / 68 | 37 / 57 / 51 | 0.93 / 0.83 / 0.75 | 0.39~0.90 |
| nofb 静态权重 | 1789 / 1027 / 741 | 235 / 116 / 131 | 207 / 91 / 110 | 0.88 / 0.78 / 0.84 | 1.0 |
| base 完整框架 | 1118 / 749 / 688 | 340 / 155 / 260 | 303 / 122 / 221 | 0.89 / 0.79 / 0.85 | 0.91~0.94 |

corruption 的重复触发率最低，为 1.2~1.9，因为随机变换不盯住同一对象。它在无引导手段中独特缺陷效率最高，但真值确认的独特缺陷仍只有 base 的三分之一上下，而且强度 3 的语义有效率已经降到 0.31~0.63。五条结论如下。第一，分类器阶段的现象在检测侧重现且更清楚：nofb 的触发记录在三个模型上全部多于 base，faster_rcnn 多 60%，但独特缺陷全部少于 base，分别是 235 对 340、116 对 155、131 对 260。静态权重反复触发同一批缺陷，动态反馈用触发量换发现量。第二，diff 是最极端的反例：faster_rcnn 上 1197 条触发记录只含 40 个独特缺陷，重复率 30 倍。纯差分梯度集中在少数锚点上反复优化，独特缺陷数甚至全面低于随机基线。它找到的少数缺陷确认率很高，为 0.75~0.93，说明方向真实但探索范围收缩。第三，真值确认的独特缺陷排序在三个模型上一致：base > nofb > random ≈ diff，合计 646 > 408 > 174 ≈ 145。每个反馈组件都对最终指标有正贡献。第四，多样性方面，nofb 在 faster_rcnn 上 235 个独特缺陷里有 203 个是 spurious，而 base 的四类分布在三个模型上都最均衡。

腐蚀算子 CorruptionMutator 使用 COCO-C 风格四种腐蚀，强度 3，替换 PGD 后用同一流程重跑（`det/corrupt.toml`）。腐蚀不使用梯度，每个目标循环仅 30 秒。结果为：覆盖增量 +0.185/+0.163/+0.153，约为梯度驱动的七成；有效失效 312/140/75；有效率 0.61/0.63/0.31，严重度 3 经常突破语义门。关键结论是：腐蚀诱发的失效保持了与 PGD 和自然失效相同的主导结构位置。fcos 的 loc 失效仍由 head.reg 主导，份额比约 2.7，自然侧为 3.6。结构分布整体跟随，幅度衰减。更换诱发手段后结构结论仍然收敛，构成结构归因结论的外部验证。需要注意，fcos 仅 75 个失效，结构比较的样本量小，正式报告时要标注。

06-13 按修正指标重跑后，结构结论从桶级细化到层级：fcos loc 的首要责任层 `head.regression_head.conv.0` 在三种失效来源下一致，自然为 3.75，生成（PGD）为 4.02，腐蚀为 2.78。其后的 conv.9/conv.3/conv.6 阶梯同样逐层对应。同一个卷积层在三种独立来源下都排第一，这是当前最细粒度的定位证据。独特缺陷指标见"五档基线对照"一节。

多强度扫描补全了收敛的稳健性。强度 1 到 5 通过逐档替换 `corrupt.toml` 的 corruption_severity 得到。fcos loc 细化表中，`head.regression_head.conv.0` 在强度 1/2/3/5 均列第一，比值为 2.43/2.78/2.74/2.90；强度 4 列第二，比值反而最高，为 4.19，P3 融合层 5.35 居首。结构结论不依赖单一强度。语义有效率随强度单调衰减，为 0.92/0.62/0.31/0.22/0.12。独特缺陷数同步走低，为 100/90/63/54/43。腐蚀验证的可用工作点在强度 1 到 2，高强度段样本量小（n=13~19），只作为方向参考。
