# Day 1 相关工作清单

本文件是 Day 1 的阅读与梳理清单，用于为论文相关工作章节打基础，并确认研究空白。文献按主题分组。每条文献都标明相关原因和需要提取的内容。

说明：下面列出的工作确认存在，但具体年份与发表会议在正式引用前仍需逐条核对。`references/` 文件夹中的 CriticalFuzz、NeuraL-Coverage 和 NSGen 有确切出处，应以本地材料为准。

阅读优先级如下：先读 E 组，因为检测失效诊断是本文的直接基础；再读 A、C 组，用于确认方法谱系；D、F、G、H 组按需要补充。

## A. 差分测试与神经元覆盖的源头

这一组是项目两条核心思路的共同起点。差分测试和神经元覆盖都来自这里。

- DeepXplore（Pei 等，SOSP 2017）。这项工作用多个功能相同的 DNN 互为参照做差分测试，并提出神经元覆盖作为引导。本项目的差分 oracle 和覆盖引导都源自这篇。需要提取：它如何用模型间分歧定位缺陷，覆盖如何进入目标函数，以及它为什么停留在分类任务，没有进入检测模型的内部结构。
- DLFuzz（Guo 等，FSE 2018）。这是一项差分式覆盖引导 fuzzing 工作。需要提取：单模型差分变异的做法，以及它与本文多模型差分的区别。

## B. 覆盖准则的发展与有效性争议

这一组支撑论文中的一个判断：为什么不使用普通神经元覆盖，而要使用关键神经元覆盖。

- DeepGauge（Ma 等，ASE 2018）。这项工作提出多粒度覆盖准则，包括 k 分段神经元覆盖、神经元边界覆盖等。需要提取：覆盖准则的设计空间，以及本文的关键覆盖如何区别于等权覆盖。
- Surprise Adequacy（Kim 等，ICSE 2019）。这项工作基于激活分布定义意外度覆盖。需要提取：用激活分布而不是阈值越界来度量充分性的另一条路线。
- DeepHunter（Xie 等，ISSTA 2019）、TensorFuzz（Odena 等，ICML 2019）。这两项是覆盖引导 fuzz 测试框架。需要提取：覆盖如何驱动样本生成的工程做法。
- 覆盖有效性争议两篇：Harel-Canada 等 "Is Neuron Coverage a Meaningful Measure for Testing Deep Neural Networks?"（FSE 2020），以及关于结构覆盖可能误导的批评工作。需要提取：覆盖升高不必然带来缺陷增加。本文用关键神经元和五维指标回应这一问题。

## C. 关键神经元引导

这一组是项目关键神经元模块的直接来源，出处以 `references/` 为准。

- CriticalFuzz。关键神经元覆盖引导的 fuzz 框架。profiling 阈值和运行时覆盖阈值本来就是两个独立参数。需要提取：关键度如何定义、覆盖如何引导，以及它为什么仍停留在分类任务。
- NSGen。神经元敏感度引导的测试生成。需要提取：敏感度作为引导信号的思路，以及它与本文归因维度的关系。
- NeuraL-Coverage（NLC）。重新审视神经元覆盖的工作。需要提取：它对覆盖度量的反思，以及它如何支撑本文的指标设计。

## D. 目标检测的测试与变异生成

这一组用于确认检测领域已有的测试工作，以及本文的研究空白。

- MetaOD（Wang 与 Su，"Metamorphic Object Insertion for Testing Object Detection Systems"，ASE 2020）。这项工作向图像中插入物体做变质测试，用于检验检测器是否漏检或误检。需要提取：检测专用的变质关系。它从输入侧制造缺陷，但不分析模型内部结构。
- DeepTest（Tian 等，ICSE 2018）、DeepRoad（Zhang 等，ASE 2018）。这些工作研究自动驾驶 DNN 的变质测试与 GAN 合成场景。需要提取：检测相关任务中的测试经验。多数工作关注端到端行为，而不是检测模型内部。

## E. 目标检测的失效诊断与错误分解

这一组是本文的直接基础，需要最先阅读。本文要把检测失效归因到结构位置，因此必须先明确检测有哪些失效类型。

- TIDE（Bolya 等，"TIDE: A General Toolbox for Identifying Object Detection Errors"，ECCV 2020）。TIDE 把检测错误分解成分类错误、定位错误、二者皆错、重复、背景虚检和漏检六类，并量化每类对 mAP 的影响。需要提取：本文四类缺陷（漏检、虚检、定位偏移、类别错误）的划分依据，并直接对齐 TIDE 的错误类型。
- Hoiem 等（"Diagnosing Error in Object Detectors"，ECCV 2012）。这是检测错误分析的经典工作，TIDE 在它之上发展。需要提取：错误分析的方法论，以及这些工作为什么停在"错误是什么类型"，没有回答"错误来自模型哪个结构"。

需要写清的 gap：TIDE 和 Hoiem 在输出层面分解错误类型。本文进一步把这些错误类型归因到模型内部的层、尺度、分支和空间区域。检测领域目前缺少这种结构层面的缺陷定位。

## F. 检测的鲁棒性、损坏与对抗

这一组为变异生成和有效性边界提供参照。

- Michaelis 等，"Benchmarking Robustness in Object Detection"。这项工作给出检测器在图像损坏下的鲁棒性基准。需要提取：检测鲁棒性的评测维度，以及它与本文语义约束的关系。
- DAG（Xie 等，"Adversarial Examples for Semantic Segmentation and Object Detection"，ICCV 2017）。这项工作研究检测器的密集对抗攻击。需要提取：检测上的梯度攻击如何构造，以及本文 PGD 式变异在检测任务中的位置。

## G. 结构归因与单元可解释性

这一组支撑结构分析方法本身。

- Integrated Gradients（Sundararajan 等，ICML 2017）、Grad-CAM（Selvaraju 等，ICCV 2017）。这些是归因方法。需要提取：本文关键神经元归因维度的方法基础，以及检测任务中应对哪个框的分数求梯度。
- Network Dissection 与单元角色分析（Bau 等，CVPR 2017 / PNAS 2020）。这些工作量化单个神经元编码什么、在网络中起什么作用。需要提取：把缺陷归因到具体神经元和结构位置的可解释性依据。

## H. 检测架构基础

这一组用于定义结构分析中的结构轴。

- FPN（Lin 等，CVPR 2017）。特征金字塔是多尺度结构的来源，对应本文的 FPN 层级轴。
- 三个目标模型的原论文：Faster R-CNN（Ren 等）、RetinaNet/Focal Loss（Lin 等）、FCOS（Tian 等），以及 SSD、YOLO 系列。需要提取：backbone、neck、head 的结构划分，以及分类分支与回归分支的分工。这些内容是结构轴的定义来源。
