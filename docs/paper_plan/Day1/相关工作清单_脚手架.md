# Day 1 相关工作清单

这是 Day 1 的阅读与梳理清单，用来给论文的相关工作章节铺底，并确认 gap。按主题分组，每条标注为什么相关、要从里面提取什么。

说明：下面的工作都确信存在，但具体年份与发表会议在正式引用前要逐条核对。references 文件夹里的 CriticalFuzz、NeuraL-Coverage、NSGen 有确切出处，以那里为准。

阅读优先级：先读 E 组（检测失效诊断），它是本文主线的直系祖先；再读 A、C 组确认方法谱系；D、F、G、H 组按需补。

## A. 差分测试与神经元覆盖的源头

这一组是项目两条核心思路的共同起点：差分测试和神经元覆盖都从这里来。

- DeepXplore（Pei 等，SOSP 2017）。用多个功能相同的 DNN 互为参照做差分测试，同时提出神经元覆盖作引导。本项目的差分 oracle 和覆盖引导都源自这篇。提取点：它如何用模型间分歧定位缺陷、覆盖如何进目标函数，以及它停在分类、没碰检测的内部结构。
- DLFuzz（Guo 等，FSE 2018）。差分式的覆盖引导 fuzzing。提取点：单模型差分变异的做法，和本文多模型差分的区别。

## B. 覆盖准则的发展与有效性争议

支撑论文为何不用普通神经元覆盖、要做关键神经元覆盖的论证。

- DeepGauge（Ma 等，ASE 2018）。多粒度覆盖准则，k 分段神经元覆盖、神经元边界覆盖等。提取点：覆盖准则的设计空间，本文的关键覆盖如何区别于等权覆盖。
- Surprise Adequacy（Kim 等，ICSE 2019）。基于激活分布的意外度覆盖。提取点：用激活分布而非阈值越界来度量充分性的另一条路线。
- DeepHunter（Xie 等，ISSTA 2019）、TensorFuzz（Odena 等，ICML 2019）。覆盖引导的 fuzz 测试框架。提取点：覆盖如何驱动样本生成的工程做法。
- 覆盖有效性争议两篇：Harel-Canada 等"Is Neuron Coverage a Meaningful Measure for Testing Deep Neural Networks?"（FSE 2020），以及关于结构覆盖可能误导的批评工作。提取点：覆盖升高不必然带来缺陷增加，这正是本文要用关键神经元和五维指标回应的问题。

## C. 关键神经元引导

项目关键神经元模块的直系来源，出处以 references 为准。

- CriticalFuzz。关键神经元覆盖引导的 fuzz 框架，profiling 阈值和运行时覆盖阈值本就是两个独立参数。提取点：关键度如何定义、覆盖如何引导，以及它仍停在分类。
- NSGen。神经元敏感度引导的测试生成。提取点：敏感度作引导的思路，和本文归因维度的关系。
- NeuraL-Coverage（NLC）。重新审视神经元覆盖的工作。提取点：它对覆盖度量的反思，支撑本文的指标设计。

## D. 目标检测的测试与变异生成

这一组确认检测领域已有什么测试工作，gap 在哪。

- MetaOD（Wang 与 Su，"Metamorphic Object Insertion for Testing Object Detection Systems"，ASE 2020）。往图里插入物体做变质测试，检验检测器会不会漏检或误检。提取点：检测专用的变质关系，它从输入侧造缺陷、但不碰模型内部结构。
- DeepTest（Tian 等，ICSE 2018）、DeepRoad（Zhang 等，ASE 2018）。自动驾驶 DNN 的变质测试与 GAN 合成场景。提取点：检测相关任务的测试经验，多数针对端到端行为而非检测内部。

## E. 目标检测的失效诊断与错误分解（本文主线的直系祖先，最先读）

本文要把检测失效归到结构位置，这一组定义了"检测有哪几类失效"，是结构分析的起点。

- TIDE（Bolya 等，"TIDE: A General Toolbox for Identifying Object Detection Errors"，ECCV 2020）。把检测错误分解成分类错误、定位错误、二者皆错、重复、背景虚检、漏检六类，并量化每类对 mAP 的影响。提取点：本文四类缺陷（漏检、虚检、定位偏移、类别错误）的划分依据，直接对齐 TIDE 的错误类型。
- Hoiem 等（"Diagnosing Error in Object Detectors"，ECCV 2012）。检测错误分析的经典工作，TIDE 在它之上发展。提取点：错误分析的方法论，以及它们都停在"错误是什么类型"、没回答"错误来自模型哪个结构"——这正是本文的 gap。

要写清的 gap：TIDE 和 Hoiem 在输出层面分解错误类型，本文进一步把这些错误类型归因到模型内部的层、尺度、分支、空间区域。检测领域目前没有这种结构层面的缺陷定位。

## F. 检测的鲁棒性、损坏与对抗

为变异生成和有效性边界提供参照。

- Michaelis 等（"Benchmarking Robustness in Object Detection"）。检测器在图像损坏下的鲁棒性基准。提取点：检测鲁棒性的评测维度，和本文语义约束的关系。
- DAG（Xie 等，"Adversarial Examples for Semantic Segmentation and Object Detection"，ICCV 2017）。对检测器的密集对抗攻击。提取点：检测上的梯度攻击如何构造，本文 PGD 式变异在检测里的落点。

## G. 结构归因与单元可解释性

支撑结构分析方法本身。

- Integrated Gradients（Sundararajan 等，ICML 2017）、Grad-CAM（Selvaraju 等，ICCV 2017）。归因方法。提取点：本文关键神经元归因维度的方法基础，以及在检测里对哪个框的分数求梯度。
- Network Dissection 与单元角色分析（Bau 等，CVPR 2017 / PNAS 2020）。量化单个神经元编码什么、在网络里起什么作用。提取点：把缺陷归到具体神经元和结构位置的可解释性依据。

## H. 检测架构基础

界定结构分析的结构轴时要引用。

- FPN（Lin 等，CVPR 2017）。特征金字塔，多尺度结构的来源，对应本文的 FPN 层级轴。
- 三个目标模型的原论文：Faster R-CNN（Ren 等）、RetinaNet/Focal Loss（Lin 等）、FCOS（Tian 等），以及 SSD、YOLO 系列。提取点：backbone、neck、head 的结构划分，分类分支与回归分支的分工，这些是结构轴的定义来源。
