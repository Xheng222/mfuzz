## A. 差分测试与神经元覆盖的源头

### A-01

- 编号：A-01
- 作者：Kexin Pei, Yinzhi Cao, Junfeng Yang, Suman Jana
- 标题：DeepXplore: Automated Whitebox Testing of Deep Learning Systems
- 年份：2017
- 发表会议 / 期刊：SOSP 2017
- 链接或 DOI：[10.1145/3132747.3132785](https://doi.org/10.1145/3132747.3132785)；[arXiv:1705.06640](https://arxiv.org/abs/1705.06640)
- 核心贡献：提出神经元覆盖，用多个功能相同的模型作为交叉引用 oracle，并把模型分歧和覆盖提升合成梯度优化目标来生成测试输入。
- 与本研究关联点：这是差分 oracle、白盒覆盖反馈和梯度驱动变异的直接源头。本文需要说明它停留在分类、自动驾驶转向和恶意软件等任务，未处理检测输出的框匹配、漏检、虚检和定位偏移。
- 任务：分类 / 其它
- 内部信号类型：输出层 / 神经元覆盖
- 是否做结构层面定位：否
- 核实状态：原文已读核实
- 来源：两者 / 本地references

- 年份：2018
- 发表会议 / 期刊：ESEC/FSE 2018 NIER
- 链接或 DOI：[10.1145/3236024.3264835](https://doi.org/10.1145/3236024.3264835)；[arXiv:1808.09413](https://arxiv.org/abs/1808.09413)
- 核心贡献：在单个模型上最大化原输入与变异输入的预测差异，同时提升神经元覆盖，以生成更容易触发错误的测试样本。

## B. 覆盖准则的发展与有效性争议

### B-01

- 编号：B-01
- 作者：Lei Ma, Felix Juefei-Xu, Fuyuan Zhang, Jiyuan Sun, Minhui Xue, Bo Li, Chunyang Chen, Ting Su, Li Li, Yang Liu, Jianjun Zhao, Yadong Wang

## 结构层面缺陷定位相关工作汇总

这一节只集中列出接近“把检测失效归因到内部结构位置”的工作，并说明它们停在哪里。

### 最接近但仍停在输出错误分解

- TIDE（E-03）：它已经把检测错误分成 classification、localization、both、duplicate、background、missed detections，并能隔离量化各类错误对 AP 的影响。它停在输出层和评价工具层面，不知道错误发生时 backbone、FPN、head 或特征图空间区域发生了什么。
- Hoiem 等（E-01）：它建立了检测错误分析方法，把 false positive 和物体属性拆开分析。它停在错误类型和输入属性层面，没有内部激活、层、尺度或分支信号。
- LRP metric（E-02）：它把检测性能拆成定位、FP、FN 三部分。它停在指标层面，不能解释这些错误在模型结构中的来源。
- Cost-Sensitive Failure Recognition（E-04）：它把 missing/false detections 与不确定性阈值相连。它停在 failure recognition 和输出筛选，不做结构责任分析。
- HOI 诊断工作（E-05、E-06）：它们把 HOI 检测错误做更细分类，并开始连接输入环境因子。它们仍不是普通目标检测器内部结构定位。

### 接近 head 分支或任务结构分析

- Double-Head（H-09）：它证明分类和定位更适合不同 head 形式，已经触及 head 内部结构功能差异。它停在架构设计和性能提升，不统计某类失效是否集中在分类 head 或回归 head。
- TSD / Revisiting the Sibling Head（H-10）：它指出分类与定位在 sibling head 中存在空间错位。这非常接近本文的“类别错误 vs 定位偏移应归因到不同分支或区域”的设想，但它仍以改进 detector 为目标，不分析具体失败样本的结构责任。
- TOOD（H-11）：它通过 task-aligned head 和 task alignment learning 对齐分类和定位。它说明任务错位是真实问题，但不把 TIDE 式错误类型回溯到 head 分支。
- GFL（H-12）：它把分类质量和定位分布建模结合起来。它显示输出分数和定位质量有耦合，但没有内部结构定位。

### 接近尺度或 FPN 结构分析

- FPN（H-02）：它定义了多尺度检测的标准结构坐标。它是本文 FPN level 轴的来源，但不是诊断方法。
- TridentNet（H-13）：它明确研究尺度和感受野分支的关系。它停在尺度分支设计，没有回答“漏检或定位偏移集中在哪个尺度”。
- YOLOF（H-14）：它重新解释 FPN 的成功原因，指出 FPN 的作用未必只是多尺度融合。它停在设计消融，不做失效类型到尺度位置的映射。
- HA-FPN（H-19）和 SNBF-YOLO（H-20）：它们说明 FPN/neck 变体会改变小目标或专用目标检测性能。它们停在架构改进，不做缺陷定位。

### 接近解释和层级归因工具

- D-RISE（G-08）：它是检测解释的关键工作，能解释某个检测输出依赖图像哪片区域。它停在输入空间 saliency，不知道责任在 FPN P4、P5 还是 head 分支。
- FSOD（G-11）：它尝试为目标检测做更快的 Shapley 解释。它主要解决检测输出解释的计算成本，仍以输入显著性为主。
- Layer-Wise Pruning for Object Detection（G-10）：它用 gradient-activation attribution 给检测网络层级贡献打分。它非常接近层级结构分析，但目标是全局剪枝，会把大量样本平均化，不能诊断单个漏检或定位偏移的运行时结构异常。
- LRP、Integrated Gradients、Grad-CAM、CRP（G-01、G-02、G-03、G-09）：它们提供从输出回溯到输入、层、通道或概念的工具。它们没有把“漏检、虚检、定位偏移、类别错误”作为因变量，也没有建立检测结构坐标系。
- Network Dissection 和单元角色分析（G-04、G-05）：它们能解释单个神经元或通道代表什么。它们不处理检测失效类型，也不分析错误在结构上的聚集分布。

### 研究空白判断

现有文献已经分别提供了四块拼图：检测错误标签、检测测试生成、检测结构坐标、归因工具。当前未核实到一篇正式工作同时满足以下条件：

- 以目标检测失效为对象，而不是只分析分类错误或通用鲁棒性。
- 使用漏检、虚检、定位偏移、类别错误等失效类型作为统一标签。
- 读取模型内部激活、梯度或结构信号。
- 把失效统计到 backbone stage、FPN level、检测头分类/回归分支、特征图空间区域等结构位置。

因此，本文可以把 gap 表述为：现有检测诊断方法能说明“检测错成什么类型”，检测架构研究能说明“结构模块承担什么功能”，解释方法能说明“某个输出依赖哪些输入区域或概念”，但还缺少把“具体检测失效类型”系统回溯到“检测模型内部结构位置”的测试与分析框架。
