# 缺陷定位与修复的验证逻辑

本文记录用修复实验验证结构定位的整体逻辑。它承接 `Day6/E8修复验证试点.md` 的试点结论，并在与用户讨论后做了一次重要修正：把修复实验的数据，从干净图像上的跨模型分歧，改成 fuzzing 生成的、能触发缺陷的输入。修正之后，本项目形成一个完整的闭环：fuzzing 产出缺陷，结构归因定位缺陷所在的结构，轻量化的定向微调在该结构上修复缺陷。后续所有修复实验都按这套逻辑设计与解读。

## 闭环：产出、定位、修复

本项目的核心主张是：结构归因能够把每一类失效的责任，定位到模型里的特定层或子网。围绕这个主张，三个环节串成一个闭环。

第一个环节是产出。反馈驱动的 fuzzing 变异种子，生成能够触发失效的输入。这些被生成出来的输入，才是本项目关心的缺陷：模型在它们上面确实失效。四类失效（虚检、漏检、误分类、定位偏移）都从这里产生。

第二个环节是定位。在生成失效上做结构归因，把每一类失效的责任定位到具体的层或子网。

第三个环节是修复。只解冻责任子网，做轻量化的定向微调，让原先触发失效的输入不再触发。修复既是缺陷的处置手段，也是对定位的验证：如果在定位到的结构上修复有效、而在对照结构上无效，定位就得到验证。即使某次修复连带损失了一些正确检测，只要它在责任结构上改变了对应失效、且明显超过对照，就为定位提供了证据。

## 为什么必须用生成失效，而不是自然分歧

早先的修复实验，包括 E8 的四类抑制试点、以及一轮 cls/loc 的定向微调，用的都是干净的 COCO val2017 自然图像，失效来自三个模型在这些图像上的跨模型分歧。这个数据基础对"修复"这个主张并不成立，原因有三。

第一，数据分布不对。缺陷是 fuzzing 在压力输入上发现的；模型在干净的、分布内的图像上本来就基本不失效。在这种数据上微调，既没有把模型暴露给触发缺陷的输入，也没有训练它去抵抗这些输入。

第二，监督信号在失效样本上最不可靠。自然分歧的"失效"按定义就是三个模型不一致的地方；既然不一致，作为监督目标的多数票本身就最可能是错的。在干净图像上，目标模型与共识不一致时，很可能目标模型才是对的。用这种目标做监督，等于把模型往一个可能错误的共识上拉。

第三，这与训练阶段冲突。自然分歧来自训练分布，模型的完整训练已经在这个分布上优化到饱和。指望轻量微调一个子网，去解决完整训练都没解决的残差，既不现实，在实验上也表现为在训练集上过拟合、在评测集上变差。

生成失效没有这些问题。变异前的种子行为是正确的，变异把它压垮，所以正确答案就是变异前的检测结果，这是一个明确可靠的监督目标。修复的含义也清楚：让这些触发输入不再触发失效。

## 三步验证逻辑与对照纪律

定位的验证分三步，全部在生成失效上进行。

第一步，假设归因正确，对每一类失效找到它的责任层或责任子网。

第二步，用简单的干预做因果探针：在责任结构上抑制或增强输出，观察对应失效是否改变。

第三步，用定向微调做修复：只解冻责任子网，用与失效匹配的损失，在生成失效上做少量多步更新。

这三步贯穿同一条纪律：每一步的证据都不是"干预让失效降了"，而是"在责任结构干预，比在对照结构干预，在同等代价下效果明显更强"。抑制那一步的对照是随机通道和最低归因通道；微调这一步的对照是随机层和最低归因层。是这个差分把"定位准确"和"随便动哪里都有效"区分开。没有对照，修复成功也证明不了定位，因为微调一个足够大的结构、在失效样本上训练几步，本来就可能把失效降下来。

## 修复协议

修复在生成失效上做，协议如下。

数据是 fuzzing 生成的、触发失效的输入。按触发输入把它们切成不相交的训练集和评测集，训练集上做微调，评测集上看缺陷是否还触发。

监督目标是变异前种子的正确检测结果（或真值）。定位偏移用 IoU 损失，把偏移框拉回正确位置；误分类用分类损失，把类别拉回正确类别。

收益看评测集上目标失效的缺陷率是否下降，代价看干净数据上的正确检测是否退化。判据沿用对照纪律：责任子网修复的幅度，在同等代价下明显超过对照层。

## 存在性维度与非存在性维度

四类失效分两类。虚检和漏检是存在性维度的失效，正确性体现在阈值上的有无，抑制这个减法算子正好对得上，免训练的通道抑制可能修得动。定位偏移和误分类都不是存在性问题：定位偏移是几何回归，框已检出、只是坐标偏了；误分类是类别竞争，框的位置对、只是类别错了。这两类不能靠把某一层输出整体调高或调低来修复，只能靠只解冻责任子网的定向微调。论文叙述按 2×2 组织：存在性失效用免训练抑制可修，非存在性失效需要定向微调。这套划分与数据来源无关，重锚到生成失效上仍然成立。

## 自然分歧结果的地位

早先在自然数据上做的结果不删除，但降级。E8 的抑制试点本来就把自身定位成因果验证、而不是修复主张（原文：通道级干预验证了归因的因果性，修复效果是旁证）。抑制是免训练的因果探针，不涉及学习，"训练已饱和"这条论证打不到它；所以 E8 在自然数据上得到的"责任通道一改，失效与正确检测的变化明显超过对照、并随强度单调"这个因果结论，作为定位的因果证据仍然成立。它被保留为自然分歧上的因果探针与负基线，正好用来对比"在分布内自然失效上微调修不动，而在生成缺陷上修得动"。被推翻的只是"在自然数据上做修复主张"这一件事，核心的因果定位证据没有被推翻。

那轮在自然数据上的 cls/loc 定向微调已经停掉。它留作上述负基线：在分布内自然失效上微调，loc 在温和档几乎不动、在激进档把 loc 和正确检测一起破坏，没有一个"小代价换失效下降"的工作点；cls 子网极敏感，单步就把误分类抬高、正确检测砍半。这正是数据基础不对时应当出现的现象。

## 结果分类

四类失效最终各落到三格之一，判定都在生成失效上做。

可定位、可修复：责任子网修复的幅度明显超过对照，定位假设得到验证。

可定位、难修复：责任与对照仍可分，责任结构对失效的影响明显超过对照，但修复幅度有限。定位成立，只是被细化成难修复。

定位不住：微调时责任子网与对照层也分不开。这才真正动摇定位。

这套分类把定位和修复分开，用"责任与对照"的差分一路贯穿三步，既能在修复成功时确认定位，也能在修复失败时区分"定位错了"和"定位对了但难修"，不会因为某一类难修就误伤整个假设。

## 前提与待办

这套设计有一个硬前提：生成失效和归因产物在之前的 output 清理中被删除了。所以第一件事是重新跑一遍 fuzzing 与分析，恢复"生成失效 → 归因 → 在生成失效上修复"这条链路的全部产物。在产物恢复之前，修复实验无法重新开始。

其次，定向微调脚本要改成从生成失效加载触发输入与变异前的正确目标，而不是从干净 val2017 取自然分歧。归因与因果探针（第一、二步）也要重锚到生成失效上。

四类失效在新数据上的具体定位结论，等产物恢复、实验重跑之后再填。本文只固定逻辑骨架。
