# Day 6 计划

1. 论文大纲。主任务是产出 `docs/paper_plan/Day6/大纲.md`。方法部分按照贡献一的流程展开四小节：差分裁判与四类判定、多维反馈 fuzzing（包含机制与评测分层原则）、结构归因（桶、层、通道；观察式证据与干预式证据）、真值核验方法。实验部分直接引用实验矩阵。主张一对应五档基线表，主张二对应 E2、E6、E7 三重验证。发现部分以"目标模型缺陷定位证据"为主要叙述，FCOS 回归分支在三种来源、五档强度下收敛作为核心证据，跨架构对比只作为判别力检查。
2. 图表清单。列出论文需要的每张表和每张图，并与现有产物一一对应；缺失的图表需要标出。预计已有数据包括五档基线表、三源层级对照表、结构收敛图、消融矩阵和真值裁决构成图。
3. 证据缺口标注。写大纲时，在每个主张相关段落旁标出证据状态。缺口映射到 E3（校准阈值，大纲后第一个实验）、多次运行统计（可夜间排队，base/random 各 3 到 5 次，产出均值区间）和 E8（修复验证，排最后）。
4. 附带任务。把 E3 的实验设计写成大纲附录中的一小节，Day 7 可以直接按此执行。
