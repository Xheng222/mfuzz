# 研究现状深度研究提示词

本文档给出两批"深度研究"提示词，供拿到外部 ChatGPT 或 Gemini 的深度研究功能后，跑大范围文献检索，每批找回约五篇核心论文。今天不写研究现状正文，正文要等核心论文带回之后再写。两批提示词都用中文写，但允许并鼓励对方检索英文文献。

使用方式很简单。把下面任意一批方括号内的整段文字复制到深度研究工具里，让它返回带出处的核心论文清单，再人工核对。每批末尾对返回格式有明确要求，便于后续直接引用。

## 本项目定位备忘

两批提示词都围绕同一个项目展开。这里先把项目立场写清楚，方便理解提示词里反复出现的措辞。

本项目叫 mfuzz，做的是"多维反馈驱动的中间层安全分析与测试框架"，研究对象从图像分类转到了目标检测。论文的头号贡献是目标检测器的结构层缺陷定位与修复。具体来说，框架先用多个检测模型相互对照（差分裁判）发现失效，把失效分成虚检、漏检、误分类、定位偏移四类；再用反馈驱动的 fuzzing 主动诱发更多失效；然后对每个失效做梯度归因，把它定位到模型内部的结构位置，比如 backbone 的某个阶段、FPN 的某个尺度、检测头的分类或回归分支，以及特征图的空间区域；最后用整层置零和通道级缩放干预来验证定位是否具有因果性，并把不依赖训练的通道抑制作为修复能减少虚检和漏检这两类存在性失效的旁证。

需要特别讲清楚本项目与 DeepFault 这一类工作的区别。DeepFault 这类方法先用谱缺陷定位思想给神经元算可疑度，挑出一批可疑神经元，再用重训练或合成新输入去修复。本项目和它们都遵循"先定位、再修复"的思路，但有三点不同。第一，对象不同。DeepFault 在图像分类网络上定位单个可疑神经元，本项目在目标检测器上把具体失效类型定位到结构位置，包括 backbone 阶段、FPN 尺度、检测头分支和特征图空间区域，而不只是孤立神经元。第二，证据链不同。本项目不止给出观察式的归因可疑度，还用整层置零和通道级缩放做干预实验，确认定位到的位置对失效有因果影响，并设置随机通道和最低责任通道作为对照。第三，修复立场不同。本项目把不依赖训练的通道抑制当作缺陷为真的旁证，而不是主要论点，并且明确指出简单抑制能减少虚检和漏检，却不能修复定位偏移和误分类这类几何型或弱归因失效。

请检索时围绕这三点差异，帮助本项目找到最接近、最值得对照和引用的核心论文。

```

4. 蜕变测试在深度学习尤其是视觉任务上的应用，包括针对目标检测和无真值场景设计蜕变关系。
```
