# Phase 5 缺陷分类与评估实验报告

## 目的

Phase 5 把前面几个阶段的运行结果整理成评估。要交付五件东西：缺陷激活向量的聚类、五维指标、结果输出与可视化、多组实验对比、结果自动校验。完成的标准是缺陷能聚出多于一个簇、能报出每类缺陷模式的样本数与类别对、五维指标齐全、校验脚本跑通。这一阶段不改变量生成逻辑，只在已有的 `FuzzReport` 上做度量和呈现。

这一阶段还顺带补上一件 Phase 2 留下的事。Phase 2 发现归因项在 softmax 饱和下近乎惰性，候选修法是换成 logit，但当时没有多样性指标没法验收，于是把判断推到了 Phase 5。现在 #Classes、OI、缺陷簇数、轮廓系数都有了，这份报告会说清这些指标当前能不能担起验收 logit 的任务。

## 指标定义

五维指标里有三个量在研究材料中只有名字、没有公式，这一阶段给出明确定义并记录在案。

单位代价缺陷数 FRE 定义为每一步像素变异换来的缺陷数，

$$FRE = \frac{\#Faults}{n_{fuzzed} \times \text{PGD步数}}$$

它和 RFT 的区别是把每个种子内部的多步迭代也算进代价。RFT 衡量每个种子的产出，FRE 衡量每一步变异的产出。

类别覆盖均衡度 OI 衡量缺陷在各原始类别上分布得均不均匀。取缺陷按源类别计数的香农熵，除以机会集合大小的对数做归一化，

$$OI = \frac{-\sum_c p_c \ln p_c}{\ln C}$$

其中 $p_c$ 是落在类别 $c$ 的缺陷占比，$C$ 是种子里出现过的共识类别数，也就是有机会出缺陷的类别总数。OI 等于 1 表示缺陷在所有有机会的类别上完全均匀，等于 0 表示全挤在一个类别或没有可分散的余地。

#Classes 定义为缺陷覆盖的不同源类别数，即缺陷里出现过的不同共识标签个数。

缺陷簇数和轮廓系数来自聚类。聚类对缺陷在关键神经元集合上的激活向量做，用余弦距离的凝聚层次聚类，在候选簇数里按轮廓系数挑最好的一个。用余弦是为了与实现方案 4.3 的路径相似度 $S_{path}$ 同一表示，也为了对个别神经元的尺度异常鲁棒。聚类前保留一条排除爆值维的兜底（见后文激活越界一节，min-max 归一化下当前不触发、排除 0 维）。轮廓系数和簇数一起报，用来表示这几簇分得清不清，不是只看分了几簇。

这三处定义是对实现方案 4.5 指标清单的具体化，原文只列了指标名。它们记在实现方案第十章。

## 产物与可视化

可视化方案单独写在 `docs/phase_5/可视化方案.md`，产物清单、数据通路和设计取舍都在那份文档。这份报告先用文字说明结果，图等数据定稿（多轮取平均）后再补。

评估的统一入口是 `evaluate.report.generate_report`。一次运行跑完，它先对缺陷聚类，再补齐多样性、语义、单位代价指标并入 `result.json`，写出缺陷张量 `defects.pt` 和聚类概况 `clusters.json`，最后画图。多组对比由 `compare_experiments.py` 出，结果校验由 `validate_results.py` 出。

## 复现

实验在仓库根目录运行，环境由 uv 管理。可视化随运行自动产出，跑下面四组 diff+cov 和一组纯差分，每个结果目录里就有各自的图。

```bash
uv run python scripts/run_fuzz.py --config configs/diff_cov.toml       # 主实验 α=0.5
uv run python scripts/run_fuzz.py --config configs/diff_cov_lam0.toml   # λ2=0 对照
uv run python scripts/run_fuzz.py --config configs/diff_cov_a0.toml     # α=0 纯归因
uv run python scripts/run_fuzz.py --config configs/diff_cov_a1.toml     # α=1 纯频率
uv run python scripts/run_fuzz.py --config configs/base.toml            # 纯差分
```

对比和校验跑在这些结果目录上。

```bash
uv run python scripts/compare_experiments.py \
    output/diff output/diff_cov output/diff_cov_lam0 output/diff_cov_a0 output/diff_cov_a1 \
    --out output/compare
uv run python scripts/validate_results.py \
    output/diff_cov output/diff_cov_lam0 output/diff_cov_a0 output/diff_cov_a1 output/diff
```

参数都在 TOML 里，和 Phase 2 同一套配置，未改动。

## 结果

### 五维指标齐全

这几组都在覆盖阈值 $t_{cov}=0.85$ 下跑（频率阈值 $t_{freq}=0.5$ 不变，两者分开的来由见实现方案第十章）。diff+cov 主实验的五维指标如下。缺陷维度共 138 个候选缺陷，RFT 0.852，FRE 0.0852。覆盖维度 CNCov 从 0.459 涨到 0.691。语义维度输入有效率 1.0、平均 $S_{input}$ 1.0，这一维是占位，要等 Phase 3 接通逐候选语义统计才有真实值。多样性维度 #Classes 59、OI 0.940、缺陷簇数 2、余弦轮廓系数 0.567。效率维度运行时间约 11 秒、单位时间缺陷数 12.9。五个维度都报出了数。

覆盖分两个量看。全局 CNCov 从 0.459 单调上升到 0.691、不饱和，和 Phase 2 一致。类关键 CCCov 类别有几十个，取跨类均值看整体：均值从 0.662 涨到 0.967，整条都明显高于 CNCov、爬得也快。各类起点都在 0.627 到 0.690 之间、彼此差异不大，结束时贴到 0.95 到 0.98（中位 0.968），类间的范围早期宽、随轮变窄，说明覆盖在往落后的类别上补。CCCov 偏快正是 Phase 2 记过的连带问题：类关键集合的关键度一半来自频率，挑出的偏向高频易覆盖神经元，所以起点高、涨得快。把覆盖阈值从 0.5 提到 $t_{cov}=0.85$ 之后，各类不再一上来就接近全覆盖，CCCov 才显出左低右高的梯度和类间差异，没有再整片饱和。

### 缺陷聚类与类别对

聚类用余弦距离的凝聚层次聚类，按轮廓系数自动选簇数（爆值维兜底排除，min-max 下排 0 维，见下一节）。主实验 138 个缺陷聚成 2 簇，余弦轮廓系数 0.567。`clusters.json` 给出了每簇的样本数与类别直方图。这次分得很不均：簇 1 有 129 个样本、横跨几十个源类别，簇 0 只有 9 个、也来自 8 个不同源类别；每簇里最常见的源类别到目标类别的对子只重复一两次。这说明聚类的分界不是按类别走的：不是"某类的缺陷归一簇、另一类归另一簇"，而是沿着一条和类别无关的内部激活轴把缺陷分成了一大一小两团。簇数确实大于一，能输出每簇的样本数和类别对，完成标准达到了。

### 跨实验对比

四组 diff+cov 的 CNCov 增长，消融关系清楚。纯频率（α=1）起点最高、最早触顶；纯归因（α=0）起点最低；融合（α=0.5）居中且涨势好；关掉覆盖目标（λ2=0）涨得最慢。

CCCov 取每轮跨类均值横向比，消融关系和 CNCov 同向。融合与纯频率末轮都到 0.94 以上；纯归因起点最低、只到 0.766；关掉覆盖目标从 0.662 涨到 0.813、垫底。覆盖目标开和不开（diff_cov 对 λ2=0）起点同是 0.662，CCCov 跨类均值增益 0.304 对 0.151，和 CNCov 一样正好翻倍，说明覆盖目标对类关键覆盖也实打实地推。关键标量的横向对比如下。

| 实验 | 模式 | #Faults | RFT | CNCov 增益 | CCCov 增益 | #Classes | OI | 簇数 | 余弦轮廓 | 越界神经元 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| diff | 纯差分 | 158 | 0.975 | — | — | 62 | 0.953 | — | — | — |
| diff_cov | 融合 α=0.5 | 138 | 0.852 | 0.233 | 0.304 | 59 | 0.940 | 2 | 0.567 | 3024 |
| diff_cov_lam0 | λ2=0 | 158 | 0.975 | 0.092 | 0.151 | 62 | 0.953 | 2 | 0.706 | 957 |
| diff_cov_a0 | 纯归因 α=0 | 158 | 0.975 | 0.118 | 0.295 | 62 | 0.954 | 2 | 0.830 | 2197 |
| diff_cov_a1 | 纯频率 α=1 | 145 | 0.895 | 0.237 | 0.169 | 61 | 0.952 | 2 | 0.509 | 1398 |

开覆盖目标把 CNCov 增益从 0.092 抬到 0.233，翻了一倍多；同时缺陷数从 158 降到 138、RFT 从 0.975 降到 0.852，是梯度预算分一部分给覆盖探索的代价，覆盖与缺陷此消彼长。把覆盖增益、缺陷数、RFT、OI、簇数并排看，纯差分没有覆盖增益和簇数（不记激活向量），各配置 RFT 都在 0.85 以上、缺陷数落在 138 到 158 之间。

纯差分模式没有覆盖历史，记的是目标置信度随 PGD 步数下降，从 0.485 掉到 0.002，说明差分目标在持续把目标模型往偏离共识类别的方向推。

缺陷的语义质量从扰动幅度看：L∞ 扰动 0.03，原始与变异图肉眼几乎看不出区别，但模型的判断已经从源类别偏到了目标类别。

### 激活越界

缺陷激活向量按每个神经元自己的 profiling 区间做 min-max 归一化，正常落在 [0,1]。$\hat c>1$ 是对抗把神经元推过 profiling 上界，$\hat c<0$ 是跌破下界，两头都算越界，回答"有没有大量关键神经元被推出训练范围"。主实验有 3024 个关键神经元越界（占 13780 个关键神经元的 21.9%），$\hat c$ 落在 $[-0.751, 1.708]$——极值在个位数量级，是对抗推出训练范围的真实信号，不是归一化产物。

越界量随配置变。纯归因（α=0）2197 个（15.9%），$\hat c$ 最高到 3.105；纯频率（α=1）1398 个（10.1%）；融合（α=0.5）3024 个（21.9%）；关掉覆盖目标（λ2=0）只 957 个（6.9%）。开覆盖目标会把更多神经元往自身区间高位推，越界数自然涨上去。

这里要记一笔归一化的修复，正好接上 Phase 2 的归因惰性。早期实现用"除以正向峰值"的归一化，在常为负、正向峰值近零的神经元上，会把激活除以地板值 $10^{-8}$、爆到 $10^9$ 量级，而且这种神经元被归因通道选得越多爆得越凶（纯频率 0 个、融合 297 个、纯归因 434 个）。换成区间 min-max 归一化后，分母是真实区间宽度、不再近零，$10^9$ 爆值彻底消失，只剩上面这套有界的越界信号；metrics 也从早期"越界档 $>5$ 加爆值档 $>1000$"两档简化成单一越界档。聚类里那条排除爆值维（$|\hat c|>1000$）的逻辑因此当前不触发、排 0 维，留作兜底。

越界本身是正常现象——对抗本就要把神经元推到训练没见过的区间。validate 把它作告警级（warn）、不判失败，只在越界占比超一成时提示。主实验 21.9% 触发了这个提示，是预期之内。

### 自动校验通过

五组实验的 `result.json` 都过了第七章的 error 级检查。关键占比 0.50 落在 0.30 到 0.82、CNCov_0 明显小于 1 且不在第一轮饱和、有未覆盖神经元时覆盖梯度大于零、RFT 大于零、缺陷簇数大于一，这些都通过。激活越界是告警级（warn）不是错误级：越界本身正常，不让它判实验失败；主实验越界占比最高 21.9%、λ2=0 对照最低 6.9%，都只是提示。（顺带修了一处与结果无关的小问题：校验脚本在 Windows 非 UTF-8 输出下打印越界详情里的 ĉ 字符会崩，按图表惯例把字面量换成 c_hat 后正常。）跨实验才能判定的项（diff+cov 覆盖高于纯差分、融合对纯频率、动态对静态）标成跳过，交给对比环节。纯差分模式的覆盖、聚类相关项按模式跳过。

## 观察与建议

聚类这一维的方法选择值得讲。早期用标准化加欧氏距离的 ward 聚类，轮廓系数只有 0.23 上下，看着像"缺陷没什么多模态结构"。换成余弦距离、去掉标准化之后，主实验轮廓系数升到 0.567，簇划分也更干净。原因有二：余弦与实现方案 4.3 的 $S_{path}$ 同一表示，且对单样本整体归一、不怕个别维的尺度异常；标准化反而把近乎不变的噪声神经元抬到和有区分力的神经元同等权重，压低分离度。聚类前还留着一条排除爆值维的兜底，那是针对早期峰值归一化爆值的；换成 min-max 后 $\hat c$ 有界、无维触发，当前排 0 维，结论不再依赖这条排除。

换方法之后结论站得更稳，而且轮廓系数随归因占比单调走高：纯频率（α=1）最低 0.509，融合 0.567，λ2=0 对照 0.706，纯归因（α=0）最高 0.830。也就是归因占比越大、缺陷指纹越分得开，这和"频率挑出的神经元偏同质、指纹趋近"一致。要说清的是，轮廓系数高只代表两团分得开，不代表多样性就高——四组都稳定在 2 簇，当前缺陷的内部路径就是个粗的双峰，多样性有限，但这个有限是真实的，不再是前处理造成的假象。还要补一句，缺陷集本身有 CUDA 非确定性，簇数和轮廓系数稳定，具体落到哪个样本的二分会有小幅浮动。

OI 和 #Classes 当前接近天花板，要小心解读。OI 都在 0.94 到 0.95 上下，#Classes 都接近共识类别总数（59 到 62）。原因是种子池按类别大致均衡、且几乎每个种子都触发缺陷（RFT 都在 0.85 以上），缺陷于是基本继承了种子的类别分布，自然又广又均。这两个数高，反映的是均衡种子加高触发率，不是方法在多样性上有特别之处。换句话说，在当前设置下 OI 和 #Classes 已经饱和、区分不出配置之间的差别，表里这两列几乎一样就是证据。

这件事直接影响 logit 修法的验收。Phase 2 把 logit 的判断推到 Phase 5，指望用 #Classes、OI、缺陷簇数来比 softmax 和 logit 谁好。现在看，#Classes 和 OI 已经饱和、当不了区分信号，真正可能敏感的是聚类轮廓系数和 CCCov 的跨类离散度——前者直接受归因项质量影响。修正聚类方法后，轮廓系数已经能区分 α（纯频率 0.509、融合 0.567、纯归因 0.830，归因占比越高越分得开）。原先还想把"归因拉进的死神经元数量"当信号，但那是早期峰值归一化的爆值产物，min-max 已经把它消掉了，不再适用。所以验收 logit 的标准收紧到"看聚类分离度和 CCCov 跨类区分度"。这份报告把这条标准定下来，但 logit 实验本身还没跑：要把 profiler 的 $F(x)_c$ 从 softmax 概率换成 logit，重跑 profiling 和这几组实验，再比这两个量。这是一个独立的后续动作，留给后面做。

语义维度现在是占位。输入有效率和平均 $S_{input}$ 都是 1.0，因为 Phase 3 还没接，缺陷记录里的 $S_{input}$ 是默认值。评估管线已经把这一维的位置留好了，Phase 3 一接通逐候选语义统计，这两个数就有真实值，校验里那条"输入有效率不过低"也会从占位变成真检查。

FRE 在当前设置下区分度也有限。它约等于 RFT 除以 PGD 步数，几组实验步数都是 10、RFT 都在 0.9 以上，于是 FRE 都挤在 0.09 附近。FRE 要在不同步数预算的实验之间比才有意义，同步数下它跟着 RFT 走。

## 结论

Phase 5 达标。五件交付物都到位：缺陷激活向量聚类、五维指标、结果输出与可视化、多组实验对比、结果自动校验，对应的两个脚本 `validate_results.py` 和 `compare_experiments.py` 也跑通了。缺陷聚出 2 簇、能输出每簇的样本数与类别对，五维指标齐全，校验脚本对五组实验全部通过。可视化方面，运行会产出单实验的覆盖曲线（CNCov 与 CCCov 同图）、CCCov 热力图、缺陷对比、聚类散点，跨实验的 CNCov 与 CCCov 叠加、指标柱状图，五个维度都有承接的产物（清单见可视化方案，图等数据定稿后再补进报告）。

诚实记下几条边界。一是缺陷只稳定分出两个粗簇，内部路径多样性有限；不过换成余弦距离、去标准化后这个二分是真实的、主实验轮廓系数 0.567，不再是前处理造成的假象。二是 OI 和 #Classes 已饱和，在均衡种子加高触发率下当不了配置之间的区分信号，验收 logit 的标准因此收紧到聚类分离度与 CCCov 跨类区分度。三是早期的一处归一化缺陷已经修掉：峰值归一化在常为负的神经元上会爆到 $10^9$ 量级，换成区间 min-max 后分母不再近零、爆值消失，现在只剩有界的激活越界信号（主实验越界占比 21.9%），作为正常结果报出。四是语义维度仍是占位，等 Phase 3。这些都不影响 Phase 5 本身的交付，但决定了后面几步往哪使劲。
